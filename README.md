

## GUI Visualization Instructions

This repository includes an interactive GUI for visualizing the misinformation spread simulation.

### Required Folder

Make sure the `charliehebdo` folder is present in the root of the repository. This folder contains the required data files. Without it, the GUI will not function correctly.

### Usage Steps

1. In the **data loading section** of the GUI, manually add the `charliehebdo` folder.
2. Click the **"LOAD DATA"** button to initialize the simulation environment.
3. After running a series of steps, **refresh the page** to trigger the updated visualizations.

> **Note**: Visualization panels below the simulator will not update automatically after each step. A manual refresh is needed to see the latest results.
